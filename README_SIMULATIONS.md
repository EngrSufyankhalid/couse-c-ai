# AURA demonstration transcripts (synthetic)

These six files are **fictional illustrative examples** of how a Socratic exchange and Galilean debate *might* look. They were authored for demonstration and **are not transcripts from Gemini, ChatGPT or Claude**. The model names are labels for fictional example styles, not provenance or verified performance.

## Suitable uses
- Show the dialogue formats during a presentation.
- Use as example inputs for discussing the rubric (without scoring actual models).
- Demonstrate state transitions and persona differences.

## Not suitable uses
- Claiming these logs as real API executions.
- Assigning empirical comparative scores to Gemini, ChatGPT or Claude.
- Replacing the required real model evaluation.

The existing `05_Execution_Transcript.txt`, if generated by a successful Gemini API run, is the genuine execution evidence. For the cross-model evaluation, collect at least one real output from each model or explicitly report that cross-model testing has not been completed.
