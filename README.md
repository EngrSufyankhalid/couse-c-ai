# AURA Dialogic Engine — Mission 1

Conversational AI (Winter Semester 2026/27): Python implementation of (1) a Socratic discovery loop and (2) a Galilean three-persona debate. Assignment source: `ps01.pdf` (provided separately).

## Files

- `01_Alignment_Brief.md` — philosophical analysis, evaluation rubric, system persona
- `02_Socratic_Protocol_Map.md` — state diagram, pseudocode, dry-run explanation
- `03_Galilean_Sandbox.md` — personas, scenario, safety audit
- `04_dialogic_engine.py` — working engine code (requires actual API access)
- `05_Execution_Transcript.txt` — GENERATED BY RUNNING THE SCRIPT, not included until verified
- `.env.example` — placeholder for API key; copy to `.env` locally
- `requirements.txt` — dependencies
- `TEAM_HANDOFF.md` — review and presentation responsibilities

## Install (Windows PowerShell, VS Code terminal)

Prerequisites: Python 3.10+; VS Code. Install Antigravity (agy) if required by the course and document its use honestly.

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
Copy-Item .env.example .env
```

Get an API key from https://aistudio.google.com/api-keys and paste it into `.env`:

```text
GEMINI_API_KEY=your_private_key_here
```

Select a free-tier-eligible model available in your account; the example currently defaults to `gemini-2.5-flash`. If this model is not available on your account, set `GEMINI_MODEL` in `.env` to an eligible model from Google's live model listing and check pricing before running.

## Run

```powershell
python 04_dialogic_engine.py --mode both --rounds 3
```

The script calls the real Gemini API and writes a timestamped `05_Execution_Transcript.txt` only after completing all selected modes. An ordinary `both` run simulates the Socratic respondent **using the model** and explicitly labels that; for a genuine human-in-the-loop dialogue, use:

```powershell
python 04_dialogic_engine.py --mode socratic --interactive --rounds 3
```

Other commands:

```powershell
python 04_dialogic_engine.py --mode galilean
python 04_dialogic_engine.py --mode socratic --premise "A helpful AI should always obey users." --rounds 2
```

**Caution:** Running one mode overwrites the default transcript file. Preserve the final both-mode run for submission. Do not upload `.env` or any actual API secrets.

## Validate

1. Run `python -m py_compile 04_dialogic_engine.py`.
2. Confirm actual model responses appear in the terminal and the output file.
3. Confirm three debate personas have distinct arguments.
4. Inspect contradiction judgments manually; record where the model fails.
5. Check that any aporia or maximum-round termination is identified correctly.
6. Populate the LLM comparative evaluation section in `01_Alignment_Brief.md` with real observations.
7. Have each role owner verify the files and explain their component.

## Interpretation cautions

The Socratic contradiction auditor is LLM-based and can be wrong. The script proposes tentative refinements rather than treating them as user consent. The three-persona mode is sequential role prompting on the same provider, not independent calibrated agents. See both Markdown deliverables for limitations.
